# Buy Box

> This is the only file the system asks you to write, and it is the file every
> skill reads. Ten minutes here decides whether the ranked list is useful or
> plausible-looking rubbish.
>
> Three rules while filling it in:
>
> 1. If something does not apply, write `N/A`
> 2. If you do not know yet, write `TBD`. The system will ask rather than invent
> 3. Answer section 1 properly. It changes what the system is allowed to do
>
> Prefer to do this by talking? Start Claude Code in this folder and say
> **"help me fill out my buy box"**.

Last updated: `YYYY-MM-DD`
